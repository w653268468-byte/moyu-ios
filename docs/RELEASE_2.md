# Gavin 2.0 重构预览

书源管理增加显式删除、多选删除、JSON 编辑、禁用、导出、分组搜索与整链路校验。删除书源保留书架与缓存。支持基础 JSONPath、静态 GET/POST 和更具体的网络错误。

本地增加 EPUB、PDF、Markdown、HTML、RTF、DOCX 文字导入。阅读设置增加字距、段距、边距、缩进、主题、亮度、常亮与预览，提供系统语音听书、完整备份和恢复。移除番茄专用接口。

这不是 Legado 完整移植：完整 Java/Android 桥、EPUB 原版式和 MOBI/AZW3 尚未完成。书源网站可用性需要手机实际网络校验。

下载 `Gavin-unsigned.ipa` 后用 Sideloadly 签名，使用同一账号覆盖安装。先从旧版备份“文件 → 我的 iPhone → Gavin”下的两个文件夹；不要先卸载旧版，以免删除阅读数据。

每次此预览更新的实际构建提交请查看最新成功的 Actions。源码包与 IPA 由通过测试和 iOS 构建的同一个工作流生成。

- 新增全屏按屏幕分页，本地与在线统一；中心呼出菜单，两侧点击或滑动翻页。支持重排和位置记忆，可选择平移或原生仿真卷页；取消卷页手势保留当前进度。

- 新增 JSONPath 过滤/切片/并集/递归，以及 QuickJS 脚本执行、常用选择器/Jsoup/编码/哈希/HTTP 接口和动态网址/请求头。复杂 Android 桥仍不完整。
- 扫描 PDF 自动尝试本机 OCR，导入显示进度并可取消；DRM 支持已从需求移除。
- 新增网页登录及 Cookie 复用；实际网站验证尚需逐站验收。

- 新增发现分类与分页、在线精确滚动恢复、自动与手动换源。自动换源核对书名、作者及章节并先验证正文，替代失败保留原书。

- 新增 WebDAV 完整快照同步：钥匙串保存账号，ETag 条件上传，冲突由用户选择。下载前保存本机恢复副本；需要配置自己的 HTTPS WebDAV 文件夹，尚未连接用户实服验收。
