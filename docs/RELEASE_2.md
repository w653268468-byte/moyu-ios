# Gavin 2.0 重构预览

本轮重点为找书搜索：全源/分组/指定书源、搜索历史、同书名同作者聚合与多源选择、相关度/源数/书名/速度排序、书名/作者与精准筛选、停止后继续剩余书源、单源重试与独立分页。搜索规则和正文规则兼容性分别检查，正文不兼容不再直接阻止搜索。结果显示可用的封面、分类、字数和最新章节。

书源脚本补充 setContent/getElement、URL 提取、毫秒时间格式、Hex、UUID、繁简转换及 WebView UA；普通规则使用局部 let/const 作用域，公共脚本库显式共享定义。嵌套脚本和完整 Java/Android 接口仍未实现。

继续优化：重新搜索相同关键词使用全新会话，停止恢复和分页保留当前会话；新增原生搜索状态检查，覆盖迟到响应和恢复未完成源。脚本增加 MD5 的 16 位输出、SHA-1/256/384/512 摘要、HMAC 的 MD5/SHA 系列 Hex/Base64 输出及 Base64 有符号字节数组；AES、RSA 与完整 CryptoJS 尚未接入。

设置首页改为常用操作入口，格式和技术说明移至“帮助与关于”。新增 TTF/OTF/TTC 字体导入、选择与删除，字体随完整备份和 WebDAV 快照保存；文字分页和滚动使用同一字体。新增在线书签与备注，按章节及 UTF-16 位置保存，换源后找不到唯一章节时会提示。

听书改为共享播放器，长章节分段、自动接章、保存朗读位置、暂停恢复、定时停止、读完本章停止、锁屏/控制中心指令及耳机断开暂停已接入。退出阅读页保留播放。自动接章状态机和音频输出分别验证；真机锁屏持续音频和来电中断仍需单独验收，不能用模拟音频测试替代。

书源添加优先修复：统一入口自动识别网址或完整 JSON；20 条限制只计算网址，文件选择支持无扩展名 JSON。预览支持全选/逐项勾选，确认导入按钮固定在底部。下载详情显示实际重定向地址、字节数与具体错误；单个链接失败保留其他成功结果。原生集成检查覆盖重定向、粘贴 JSON、部分失败、保存重开、重复更新以及搜索→目录→正文；这不代表所有外部网站已经可用。

找书新增多书源并发搜索、渐进显示结果、各书源独立分页、失败详情与仅重试失败页；停止搜索后保留已找到的结果。书源兼容性和网站可用性仍需真实网络验证。

书源管理增加显式删除、多选删除、JSON 编辑、禁用、导出、分组搜索与整链路校验。删除书源保留书架与缓存。支持基础 JSONPath、静态 GET/POST 和更具体的网络错误。

本地增加 EPUB、PDF、Markdown、HTML、RTF、DOCX 文字导入。阅读设置增加字距、段距、边距、缩进、主题、亮度、常亮与预览，提供系统语音听书、完整备份和恢复。移除番茄专用接口。

这不是 Legado 完整移植：完整 Java/Android 桥仍未完成，格式兼容性仍需扩大样本验收。书源网站可用性需要手机实际网络校验。

下载 `Gavin-unsigned.ipa` 后用 Sideloadly 签名，使用同一账号覆盖安装。先从旧版备份“文件 → 我的 iPhone → Gavin”下的两个文件夹；不要先卸载旧版，以免删除阅读数据。

每次此预览更新的实际构建提交请查看最新成功的 Actions。源码包与 IPA 由通过测试和 iOS 构建的同一个工作流生成。

- 文字分页默认点击屏幕任意阅读位置都到下一页，长按打开菜单；可切换经典左右分区，或用九宫格自定义点击动作。本地与在线文字阅读共用配置；支持平移、仿真卷页、重排和位置记忆。EPUB 原版式视图仍采用滚动和书内链接。

- 新增 JSONPath 过滤/切片/并集/递归，以及 QuickJS 脚本执行、常用选择器/Jsoup/编码/哈希/HTTP 接口和动态网址/请求头。复杂 Android 桥仍不完整。
- 扫描 PDF 自动尝试本机 OCR，导入显示进度并可取消；DRM 支持已从需求移除。
- 新增网页登录及 Cookie 复用；实际网站验证尚需逐站验收。

- 新增发现分类与分页、在线精确滚动恢复、自动与手动换源。自动换源核对书名、作者及章节并先验证正文，替代失败保留原书。

- 新增 WebDAV 完整快照同步：钥匙串保存账号，ETag 条件上传，冲突由用户选择。下载前保存本机恢复副本；需要配置自己的 HTTPS WebDAV 文件夹，尚未连接用户实服验收。

- 新导入 EPUB 保留原始文件、图片、CSS 与目录，提供原书样式/文字重排和章节内位置恢复。页面脚本禁用且阻止远程资源；旧版仅文字 EPUB 需重新导入原文件。备份及 WebDAV 也包含原书。

- 新增未加密 MOBI/AZW3/KF8 导入，转换为保留图片/目录的 EPUB，使用 libmobi（LGPL-3.0-or-later）。源码包包含库源码、许可证及可重建工程。
