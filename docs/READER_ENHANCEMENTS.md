# 本批阅读体验改进

状态：代码已实现，等待 macOS 编译、原生检查和界面回归；不能据此声称整体达到安卓阅读九成。

| 项目 | 本批改动 |
| --- | --- |
| 书源体检 | 独立检测会话、稳定复核会话；一个子请求中断不终止整批。完整体检显示搜索、目录、正文阶段。停止保留结果，可继续剩余源或仅重试失败源；添加分组筛选、批量分组和健康/速度排序。 |
| 搜索速度 | 沿用健康排序及 1—8 路并发，默认取得 20 条来源结果后暂停其余请求；可设 10/20/50/100 或关闭，并继续剩余搜索。条数是来源结果数，不等于去重后的书籍数。 |
| 预加载 | 固定两章、关闭或按近期翻页速度预取约五分钟的 2—6 章；最多两路并发。自动缓存预算 50/100/200/500 MB，仅清理跟踪的自动预取文件，保留当前章及手动离线下载。 |
| 换源 | 健康源优先、显示近期响应及最新章节，支持目标正文预览；同书同章且文本锚点唯一时保留章内位置，否则从目标章开头继续。 |
| 更新管理 | 新增章节更新中心，集中显示未读更新及失败原因；可只重试更新失败的书籍。 |
| 发现内容 | 收藏常用发现源、今日不感兴趣、长期屏蔽及取消屏蔽。过滤后网站榜单仍保留原始名次，不伪造榜单；每日推荐是书源内容轮换。 |
| 阅读记录 | 本地、在线、EPUB 阅读页记录前台时长，按日展示书籍、章节及统计；后台、设置面板和两分钟无翻动时暂停。记录在本机并纳入完整备份，历史入口继续书架最新进度。 |

未增加 Wi-Fi 传书；按用户后续说明，不替用户删除圈出的三个书源。

新增回归覆盖 2360 个任务中单源取消不拖停批次、父任务停止、404 复核与搜索会话隔离、预取预算保护、文本锚点、每日阅读合并及持久化。模拟及回环测试不等于每个真实网站或手机网络已通过。
