# 番茄小说导入

在 App 底部打开「书源」，找到「番茄小说 · 分享链接导入」。

1. 从番茄复制小说的官方分享链接，粘贴到输入框；整段分享文案、官网详情链接、官网章节链接和数字书籍 ID 均可识别。
2. 点「识别番茄小说并获取目录」。成功后会显示官网返回的书名、作者、简介和章节目录。
3. 点「加入书架」，以后可从「书架 → 在线藏书」打开。
4. 点「继续阅读」或选择章节。官网返回普通正文时使用原生阅读器；需要网站特殊字体时会提示，点击「官方网页」使用原站页面阅读。

这是通用的链接导入适配，不针对某一本书写死。当前识别 `fanqienovel.com` 及其子域名；其他域名的分享跳转请先在浏览器打开，再复制番茄官网的最终地址。

## 目前的实际范围

- 只读取官网公开返回的信息和目录，没有番茄全站书籍数据库，也不承诺所有作品、全部章节都可原生提取或离线下载。
- 目录以官网当前页面实际返回为准，最多 20000 章。若没有公开目录，会显示失败原因，同时保留官方网页打开入口。
- 网站需要登录、验证、官方 App 或其他访问条件时，按原站流程处理。App 不接收番茄密码，也不执行第三方书源脚本。
- 官方网页阅读保持原站的字体和交互；网页内部的阅读进度由网站管理，不同步到原生章内进度，也不作为纯文本缓存。
- 本地缓存只包含成功获取到的普通正文。特殊字体编码会被识别并提示，避免静默保存乱码。

## 验证记录

2026-10-18，使用一个公开官网样例检查到 100 个不同章节链接，书籍详情和章节页均返回 HTTP 200；章节正文采用特殊字体编码。因此该样例应使用官方网页阅读。测试覆盖通用分享文案、数字 ID、伪冒域名拒绝、目录顺序、去重、空目录、普通正文与特殊字体提示，不代表已测试全站所有书籍。
