# 重构需求与验收清单

用户要求：iPhone 原生可安装、公开源码；Windows + iPhone 可编译/签名；以 Android 阅读/Legado 为功能目标；导入 Legado JSON 链接；书源批量管理与失效删除；完整阅读设置；多格式本地书；删除番茄独立接口。未点名的常用能力也需检查。

## 本轮必须验证

- 书源：搜索/分组、启用禁用、编辑、导出、批量删除；删除有关联小说的书源不能被静默阻止，保留已下载内容并提示重新关联。
- 错误：导入链接下载、搜索、目录、正文分别报告 URL 主机和 HTTP/网络原因；不支持的规则不能显示成超时。
- 规则：现有 CSS + 旧式选择器；增加 XPath、JSONPath 基础路径、GET/POST 静态请求。真实书源与合成测试分别报告。
- 本地：TXT/EPUB/PDF/MD/HTML/RTF/DOCX；无文字层 PDF 已接本机 OCR；DRM 已排除，不将纯文字导入宣传为原版式渲染。
- 阅读：字号/字体/字重/字距/行距/段距/边距/首行缩进/主题/亮度/屏幕常亮/预览/恢复默认；本地在线统一。
- 通用：设置页、导入导出、备份恢复、听书、章节缓存、取消请求、阅读位置和旧版兼容。
- 移除番茄专用入口、解析接口；保留旧书架记录并明确迁移说明。
- 云端测试、iOS 模拟器与真机架构构建；新 IPA 保持 bundle id，建议覆盖安装保留数据。

## 完整对标尚需逐项验收（不能宣称已等同 Legado）

完整 Java/Android 脚本桥、JS/XPath/复杂 JSONPath、发现页、WebView 验证、Cookie 登录、自动换源、仿真卷页与翻页动画选项、EPUB 图片原版式/目录、扫描 PDF OCR、MOBI/AZW3、WebDAV 同步、订阅规则、替换净化与全文跨书搜索。

这是一份验收记录，不以“界面上有开关”代替实现与测试；每项结果以更新说明及 CI 为准。

## 全屏分页

本地和在线阅读共用 CoreText 屏幕分页：左右滑动翻页；默认全屏点击下一页，长按打开菜单，也可用九宫格配置点击动作；隐藏导航、底部章节控制、状态栏，保留安全区域与页码。字号/行距/边距/横竖屏变化重新分页，按章节 UTF-16 偏移保存位置；页末跨章。提供整张纸面的平移、原生仿真卷页和滚动模式。原有本地分段用于搜索索引，屏幕分页不受 800 字分段边界限制。
